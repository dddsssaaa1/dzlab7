# Домашнее задание к работе 7

## Условие задачи (Вариант 11)

Составить программу, которая для заданного числа от 1 до 12 выводит его отображение римскими числами.

* * *

## 1. Алгоритм и блок-схема

### Алгоритм

1. Установить локаль для корректного вывода текста.
2. Запросить у пользователя число `n` от 1 до 12.
3. С помощью оператора `switch` выбрать вариант по значению `n`:
   - при `n` от 1 до 12 вывести соответствующее римское число (I, II, III, IV, V, VI, VII, VIII, IX, X, XI, XII);
   - при любом другом значении вывести сообщение о том, что число вне диапазона.
4. Завершить программу.

### Блок-схема
